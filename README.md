# Hospital Management System (DB + Web Project)

A complete **Hospital Management System** developed using **Node.js, Express.js, MySQL, HTML, CSS, JavaScript, and jQuery**.
This project helps manage different hospital operations such as patients, doctors, staff, wards, medicines, services, and billing.

## 🚀 Features

* 👨‍⚕️ Doctor Management
* 🧑‍🤝‍🧑 Inpatient & Outpatient Management
* 💊 Medicine Management
* 🏥 Ward Management
* 👩‍💼 Staff Management
* 🧾 Billing System
* 🔍 Patient Existence & Bill Status Checking
* 📋 Services Management
* 📄 View / Update / Delete Records
* 🎨 Responsive Frontend using HTML, CSS & JavaScript

## 🛠️ Technologies Used

* Frontend:

  * HTML5
  * CSS3
  * JavaScript
  * jQuery

* Backend:

  * Node.js
  * Express.js

* Database:

  * MySQL

## 📁 Project Structure

* `public/` → Frontend files (HTML, CSS, JS, Images)
* `server.js` → Main backend server
* `model.js` → Database connection & queries
* `SQLQuery1.sql` → Database SQL file

## ⚙️ Installation Steps

1. Clone the repository:

```bash
git clone <your-repository-link>
```

2. Install dependencies:

```bash
npm install
```

3. Import the SQL file into MySQL:

```bash
SQLQuery1.sql
```

4. Start the server:

```bash
node server.js
```

5. Open in browser:

```bash
http://localhost:4000
```
